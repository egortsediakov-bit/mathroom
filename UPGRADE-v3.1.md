# Обновление Mathroom Web v3.0 → v3.1

Эта версия рассчитана на уже работающий GitHub Pages + Supabase проект.

## 1. Не трогай текущий `config.js`

В архиве v3.1 специально **нет** `config.js`, чтобы ты случайно не перезаписал уже рабочие `SUPABASE_URL` и Publishable key. В GitHub оставь существующий `config.js` как есть.

## 2. Обнови Supabase

Открой Supabase → SQL Editor → New query, вставь целиком файл:

`supabase/upgrade-v3.1.sql`

и нажми **Run**.

Он:
- добавит очередь задач урока и live-состояние;
- добавит безопасную отправку домашних/тестов через RPC;
- не даст ученическому браузеру читать `correct_answer`;
- добавит метаданные категории/тегов в результаты;
- включит realtime для live-состояния урока.

Старые таблицы и данные не удаляются.

## 3. Обнови файлы GitHub Pages

В репозитории `mathroom` загрузи с заменой:

- `index.html`
- `404.html`
- `app.js`
- `styles.css`
- папку `js/`
- папку `supabase/` (можно хранить в репозитории как исходники миграций)

Не удаляй свой существующий `config.js`.

После commit GitHub Pages автоматически опубликует новую версию.

## 4. Обнови backup-функцию

В Supabase → Edge Functions → `drive-backup` замени код на:

`supabase/functions/drive-backup/index.ts`

и Deploy.

В v3.1 backup дополнительно включает:
- `lesson_queue_items`
- `lesson_live_state`

Все существующие Secrets и Cron оставь без изменений.

## 5. Быстрая проверка

1. Открой преподавательский кабинет.
2. Тема → выбери ученика → `+ Домашняя`.
3. Открой ссылку ученика в инкогнито/телефоне → `Задания` → выполни работу.
4. В кабинете преподавателя → `Задания` проверь результат.
5. Начни урок → добавь несколько задач в очередь → выбери текущую задачу.
6. Включи `Фокус ученика`: на втором устройстве должна появиться текущая задача и большая доска.
7. Отметь `Решено / Сложно / Вернуться позже`.
8. Сложную задачу добавь в домашнюю одной кнопкой.
9. `Сохранить версию доски`, затем `Завершить урок`.
10. Открой `История` → урок → сохранённую версию доски.

## Что уже перенесено в облако в v3.1

- расширенная realtime-доска;
- бесконечное перемещение и масштаб;
- несколько листов;
- Undo/Redo (`Ctrl+Z`, `Ctrl+Y`), включая возврат удалённого листа;
- категории/теги банка задач;
- домашние задания и мини-тесты;
- безопасная автопроверка чисел, дробей и наборов ответов;
- очередь задач на урок;
- `Решено / Сложно / Вернуться позже`;
- текущая задача и режим фокуса ученика;
- синхронный таймер урока;
- перенос задачи в домашнюю;
- автоматический черновик отчёта по уроку;
- ручные и финальные снимки доски;
- история уроков;
- профиль ученика и базовая аналитика слабых категорий.

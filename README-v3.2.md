# Mathroom Web v3.2

Облачное обновление поверх рабочей v3.1.2.

## Новое
- приватный Supabase Storage bucket `board-assets`;
- импорт PNG/JPG/WEBP/GIF на текущий лист;
- импорт PDF: каждая страница становится отдельным листом доски;
- изображения/PDF видят преподаватель и только соответствующий ученик;
- математическая формула `∑`;
- координатная плоскость;
- построение графика `y=f(x)` (math.js);
- быстрые фигуры: треугольник, прямоугольный треугольник, квадрат, ромб, параллелограмм, трапеция;
- все новые объекты сохраняются в `board_pages`, участвуют в realtime и snapshots;
- новые имена JS-файлов/версионные query-параметры для защиты от старого кэша.

## Обновление
1. Supabase → SQL Editor → New query → выполнить `supabase/upgrade-v3.2.sql`.
2. На GitHub загрузить с заменой `index.html`, `404.html`, `styles.css`, `js/core.js`.
3. Добавить новые `app-v320.js` и `js/board-v320.js`.
4. `config.js` НЕ заменять.
5. Дождаться GitHub Pages deploy и сделать Ctrl+F5.

## Проверка
- Доска → `⇧ Импорт` → картинка.
- Доска → `⇧ Импорт` → PDF на 2–3 страницы.
- `⌗ Координаты`.
- `ƒ(x)` → `x^2 - 4`.
- `∑ Формула` → `x^2 + y^2 = r^2`.
- Открыть ссылку ученика на телефоне и проверить, что материал виден и там.

## Ограничения v3.2
- PDF импортируется максимум по 25 страниц за раз.
- PDF сначала растеризуется в браузере, затем страницы загружаются как PNG.
- Ежедневный Google Drive backup сейчас резервирует БД. Файлы из `board-assets` остаются в Supabase Storage; отдельный архив Storage → Google Drive будет следующим инфраструктурным улучшением.
